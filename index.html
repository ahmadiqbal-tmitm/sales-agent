Week 03 · Sales agent

Your own AI sales agent

It finds local businesses that fit your ideal customer, fetches their contact details, and drafts a personal first message to each one. It never sends anything: you read the drafts and send the ones you like.

Want to see how it was built? Follow the tutorial.

Step 1: Get the four things it needs (20 minutes)

This agent runs in Claude Code, on your own computer. It needs a little more setup than my other agents, and you only do it once.

  1. Claude Code. Install it from claude.com/claude-code and sign in.
  2. Python 3.10 or newer. On a Mac, run brew install python@3.12 in Terminal. On Windows, download it from python.org.
  3. Claude API access. Add billing at console.anthropic.com and set a monthly spend limit. This is separate from a Claude subscription.
  4. A Google Maps key. In Google Cloud, create a project, enable Places API (New), create a key, and restrict it to that one API.

New to any of these? The tutorial walks through each one, screen by screen.

Step 2: Install the agent (1 minute)

Open an empty folder in Claude Code and run these two commands, one at a time.

Command
/plugin marketplace add ahmadiqbal-tmitm/sales-agent
Command
/plugin install sales-agent@ahmads-build

Step 3: Let it check your setup (5 minutes)

In the same folder, say:

Prompt
Set up Sales Agent

It checks your Python, your Claude API access and your Google key, and walks you through anything that's missing.

Step 4: Describe your business (10 minutes)

Prompt
Set up a Sales Agent campaign for my business

It interviews you, then writes four short files in plain English: what you sell, which Google Maps searches to run, who counts as a good fit, and what you want to know about each lead. You can open and edit any of them.

Step 5: Run it

Prompt
Run my campaign for 20 leads

It shows you the most the run could cost and asks before spending anything. A few minutes later you have a spreadsheet of leads, with a WhatsApp opener and an email draft for each good fit.

Start with 20. Read the drafts, adjust your files, then scale up. Later runs skip every business you've already processed.

How it works

Find
Searches Google Maps for businesses like "barbershop in Dubai Marina".
Fetch
Opens each business's website and pulls out emails, phone numbers, WhatsApp links and Instagram. Plain code does this, so it costs nothing.
Qualify
A small Claude model reads a short slice of each site: the owner, the address, three useful notes, and whether the business fits your criteria.
Pitch
A stronger Claude model writes to the good fits only, using facts from your offer and their own website. It is told never to invent prices or results.
Never
Send a message, or research the same business twice.

What it costs to run

My first real run covered 20 salons in Dubai and wrote 5 pitches. It cost about $0.09 of Claude usage, and the 8 Google searches fell inside Google's free monthly allowance. Having AI researchers do the same job by hand cost me about $0.30 per business.

If something goes wrong

The Claude steps won't run
Your computer's Python is too old. Install Python 3.10 or newer.
It says a key isn't set, right after you saved it
Terminal only reads your settings file when a window opens. Quit Terminal and Claude Code, then open them again.
Google search fails with a permission error
Check that Places API (New) is enabled and that your key is restricted to that API, not a different one.
Leads are marked "check by hand"
That website blocks automated visitors or is only a booking page. Look at those few yourself.
It finds few owner names
It only reads the business's own website. Look up owners for your good fits only.
